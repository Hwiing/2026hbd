# Birthday Lab

데스크톱을 중심으로 만든 Vue 3 + Vite + GSAP 생일 웹 편지 초안입니다.

로컬에서 개발하고, 사용자가 지정한 `Hwiing/2026hbd` 저장소의 GitHub Pages로 배포합니다.

공유 주소: **https://hwiing.github.io/2026hbd/**

`main`에 푸시하면 GitHub Actions가 설치·검증·빌드를 거쳐 `dist/`를 GitHub Pages에 배포합니다. 빌드의 기본 경로는 `/2026hbd/`이며 로컬 개발 주소는 기존 `/`를 사용합니다. 원본 MP4, 바탕화면 EXE, 브라우저 프로필과 로컬 실행 로그는 Git에서 제외합니다. 사진과 추출한 음원은 배포에 포함합니다.

## 실행

```sh
npm install
npm run dev
```

`npm run build`로 `dist/`에 정적 웹사이트를 생성합니다. 서버나 데이터베이스는 필요하지 않습니다.

Pages용 빌드를 로컬에서 확인하려면 `npm run preview` 실행 후 `http://127.0.0.1:4173/2026hbd/`로 접속합니다.

## 바탕화면에서 실행

바탕화면의 **HBD Yuni.exe**를 더블클릭하면 숨김 상태로 로컬 개발 서버를 실행하고, 준비가 끝나면 Chrome(없으면 Edge)의 전용 창을 엽니다. 이 창은 `.local/browser-profile` 프로필과 자동재생 허용 옵션을 사용하여 첫 화면부터 음악을 재생합니다. 이미 켜진 서버는 재사용합니다. 기본 포트 5173을 다른 프로그램이 사용하면 5174–5182에서 빈 포트를 선택합니다.

브라우저를 닫아도 서버는 계속 실행되며 다음 실행 때 재사용합니다.

이 실행파일은 현재 컴퓨터의 프로젝트 위치와 Node.js 경로를 사용합니다. 프로젝트를 이동했다면 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-launcher.ps1`로 다시 생성하세요. 실행 로그는 `.local/launcher/`에 있습니다. 실행파일은 로컬 서버만 켜며 외부로 배포하지 않습니다.

`npm test`는 정답과 잠금 조건을 확인합니다. 개발 서버를 켠 상태에서 `npx playwright test`를 실행하면 네 관문부터 편지까지 실제 브라우저로 검증합니다. 필요하면 먼저 `npx playwright install chromium`을 실행하세요.

## 콘텐츠 교체

`src/content.js`에서 퀴즈, 정답 배열, 사진 경로와 음악을 수정합니다. 편지 본문은 **`src/letter.txt`**를 직접 읽어 표시하므로 이 파일만 수정하면 됩니다. 원문의 문장과 줄바꿈을 유지하고, 긴 문단은 읽기 좋은 장면으로 나눕니다. 사진 네 장은 편지의 문단 사이에 번갈아 배치하며, 성경 구절과 마지막 응원은 글 중심으로 보여줍니다. 편지 화면은 짙고 따뜻한 배경, 명조체, 느린 사진 전환과 줄별 등장 효과를 사용합니다.

장소 퀴즈는 `src/photo1.jpg`부터 `src/photo4.jpg`까지 순서대로 사용하며, 입력창에는 정답의 초성을 표시합니다.

음악은 로컬 원본에서 추출한 `src/audio/` 파일만 사용합니다. 원본 MP4를 웹에서 요청하거나 표시하지 않습니다.

- 소개부터 둘째 관문까지: `scott.mp3` 반복 재생. 카드 획득 화면에서도 재생 위치가 유지됩니다.
- 셋째 관문 진입: Scott을 멈추고 `diff-clip.wav` 자동 재생. 원본 Diff의 중앙인 96.27초부터 106.27초까지 정확히 10초이며 반복하지 않습니다. 다시 듣기도 가능합니다.
- 셋째 관문: `diff.png`와 `lala.png` 중 선택. 정답은 `diff.png`입니다.
- 넷째 관문: 배경음악 없이, 말랑이를 누를 때 낮고 부드러운 효과음과 놓을 때 짧게 튀는 효과음이 재생됩니다. 마우스와 Space/Enter 모두 지원하며, 소리는 Web Audio로 로컬에서 합성합니다. 비밀번호 입력 화면은 무음입니다.
- 편지 진입: `diff.mp3` 전체를 처음부터 한 번 재생합니다.

바탕화면 실행파일로 열면 음악이 기본 ON으로 자동재생됩니다. 주소를 일반 브라우저에서 직접 열어 자동재생이 차단된 경우에는 첫 클릭 또는 키 입력 후 재생을 재시도합니다. 헤더의 소리 버튼으로 직접 켜고 끌 수도 있습니다. 직접 끈 설정은 다음 장면에서도 유지됩니다.

원본을 교체한 경우 `node scripts/extract-audio.mjs <ffmpeg 실행 파일 경로>`로 음원을 다시 추출할 수 있습니다. 이 작업은 로컬에서만 실행됩니다. 추출 구간은 `src/audio/metadata.json`에 기록됩니다.

예시 정답은 다음과 같습니다.

- 빈칸 (총 2문제): 에베소서 2장 10절의 `예비` → “물론 가는 길이…” 문장의 `직선`
- 장소 (총 4문제): `보드게임카페` → `고우즈온` → `롯데시티호텔 김포공항` → `한쿡 서울타워점`. 띄어쓰기는 무시하며, 네 문제를 모두 맞혀야 두 번째 숫자 카드를 받습니다.
- 노래: 앨범 이미지 두 장 중 `Stardust` (`diff.png`) 선택
- 말랑이: 누르고 놓으며 압력을 초록 구간에 머물게 하면 다정함이 채워집니다. 마우스 또는 버튼에 초점을 두고 Space/Enter 키를 사용할 수 있습니다.
- 카드: 관문 순서대로 `1`, `0`, `3`, `1`. 네 관문 완료 후 `1031`을 입력하면 편지가 열립니다.

카드는 이 브라우저의 localStorage에 저장됩니다. `처음부터`를 누르면 초기화할 수 있습니다. 브라우저 저장소를 사용할 수 없어도 현재 탭에서는 이용할 수 있습니다.

잠금은 선물 연출을 위한 클라이언트 UI입니다. 소스에서 정답과 편지를 확인할 수 있으므로 민감한 비밀을 보관하는 보안 기능은 아닙니다.

## 구성

- 스크롤 랜딩: 흰 배경의 고정된 화면에서 큰 문장과 핵심 오브젝트가 장면별로 전환됩니다. 위로 스크롤하면 앞 장면으로 돌아갑니다.
- 검사: 단계별 잠금, 빈칸 퀴즈 2문제, 사진 장소 4문제와 초성 플레이스홀더, 멜로디, 말랑이
- 보상: 관문별 숫자 카드, 새로고침 시 진행 보존
- 마지막: 네 카드 수집 검사, PIN 검증, 잠금 해제 연출, `letter.txt` 원문과 사진 네 장을 스크롤로 읽는 편지. Diff 전체 음원이 함께 재생됩니다.
- 접근성: 키보드 스크롤과 조작, 입력 라벨, 진행률, 비활성 장면의 포커스 방지. 모션 줄이기 설정에서는 모든 장면을 일반 문서처럼 세로로 표시합니다.

잡다의 검사 흐름을 참고한 독립적인 디자인입니다.
